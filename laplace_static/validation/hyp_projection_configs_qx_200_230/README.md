grid6x4x4x4. No eigenvectors are generated by this campaign.

from job5915129. Later cases are submitted only after this regression and the
new pair pass. Checks cover counts, halo coordinates, direct samples,
translations, rank reductions, transporter factorization, unchanged spatial
and boundary links and unchanged original-field probes. SU(3) diagnostics
cover each physical central transporter window. piter40 uses the existing

The ensemble connected estimator is mean(LS_RE)/mean(L_RE)-mean(S_RAW), formed
from raw configuration averages. Per-configuration connected columns are
diagnostics, not values to average into that estimator. Sites, axes and tau
are not extra independent configurations. The n100 regression is excluded

## Run on SuperMUC

Put hyp_projection_configs_qx_200_230_integration.zip in Masterarbeit, then:

```bash
(
    set -euo pipefail
    cd /hppfs/work/pn29se/di24gus/Masterarbeit

    profiles=laplace_static/validation/hyp_projection_configs_qx_200_230
    controller=laplace_static/validation/hyp_projection_configs_qx_200_230_queue
    test ! -e "$profiles"
    test ! -e "$controller"
    unzip hyp_projection_configs_qx_200_230_integration.zip
    sha256sum -c "$profiles/package.sha256"
    sha256sum -c "$controller/package.sha256"

    bash "$profiles/build.sh"
    python3 "$profiles/prepare.py"

    first_job=$(sbatch --parsable --array=0 "$profiles/submit.sh")
    first_job="${first_job%%;*}"
    echo "Initial profile job: $first_job"
    nohup python3 -u "$controller/run_remaining.py" \
        --first-job "$first_job" \
        > "$controller/controller.out" 2>&1 < /dev/null &
)
```

The controller accepts an initial job that is pending, running or finished.
It waits for actual validated outputs before submitting indices1–11, one at
a time. Accepted IDs and provenance are retained in RUNS.json; a lock prevents
two controllers. Failure or an ambiguous submission stops future admission.
Disappearance from squeue alone is not treated as success.

Prior timing was about seven minutes per ordinary pair and fourteen minutes
for case0 with the regression. Budget 1.5–2 hours of execution, plus queue
waits. Each case uses partition/qos test and a 30-minute limit.
